# 编程 Agent 运行时

模块：`coding-agent-runtime`。依赖：[统一契约](SPEC-coding-agent-contract.md)。

## 实现与边界

主进程维护适配器注册表、连接所有权、操作互斥、会话引用和一个全局顶层运行槽位。
OpenCode 适配器复用现有服务、Plan、原生标题与 Desktop 可见模型，不启动第二个 OpenCode。
Codex 使用安装版本的 App Server stdio 协议，保留初始化、模型、历史、审批与中断的原生语义。
Kimi / Claude 未满足程序、协议或依赖前提时明确不可用，不用 OpenCode 代替执行。

原生程序只按受限绝对路径和固定参数启动，`shell: false`、隐藏窗口；提示词经协议传递。
检查程序只执行有界版本命令，不调用模型。Codex 启动过滤已知其他 Agent / 供应商认证变量，保留其原生认证环境；OpenCode 保持既有多供应商环境兼容逻辑。
不复制认证文件、不读取 key 内容、不把 Tool_box AI 配置注入原生运行时。
主进程日志只记录运行标识和状态，不记录任务正文、原始 stderr、认证结果或请求头。

通信限制单条消息、缓冲区、待处理请求、审批数量和响应时间；协议失败清理待处理项。
未知反向请求返回不支持。关闭只处理 Tool_box 自有进程，不杀独立 Desktop。
关闭时清理计时器、审批与订阅；结果未知的运行保留提示，不重试写操作。

## 本机基线与验证

实施基线：`144e402`；前一轮代码已提交为 `a16f2a4`，开始实施时工作区干净。
已通过版本命令确认 OpenCode 2.1.2、Codex CLI 0.163.0-alpha.10.2；未执行模型请求。
PATH 和标准候选路径未发现 Kimi / Claude 原生程序；不推断用户没有自定义安装。
Codex 协议以安装程序生成的 JSON Schema 与官方文档对照，不将 alpha 版本支持推断为所有版本。
无模型握手与真实推理分开记录；创建真实会话和调用模型仅在相应授权范围内执行。

合成验收使用虚拟路径 / 临时配置、纯文本项目或最小 Java 项目；不使用生产库和真实密钥。
覆盖进程崩溃、超时、拆包、断连后迟到事件、跨窗口、重复发送与取消。
执行验证遵守仓库 >500 有效代码行且 >10 文件门槛；手机不参与。
