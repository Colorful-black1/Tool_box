# 编程 Agent 统一契约

状态：按 2026-10-23 已确认计划实施；PC 主线，手机暂停维护。
模块：`coding-agent-contract`。实现索引：[执行清单](../tasks/todo.md)。

## 范围与身份

首批实例固定为 OpenCode、Codex；Kimi / Claude 枚举保留但不占日常选择器，不因程序缺失安装软件。
每种运行时首版使用一个默认原生 profile；不支持在同一运行时混用多个账号或自定义 profile。
模型选择不改变运行时。交接专用角色管理已取消，旧配置仅保留兼容校验。

- runtimeId：首版每种品牌一个运行时，标识取品牌枚举；多 profile 实例留待后续扩展。
- connectionId：每次建立 / 尝试连接的代次；仅用来隔离旧事件。
- sessionRef：Tool_box 内存中的不透明引用，绑定运行时、连接、项目和 nativeSessionId。
- runId：一次顶层发送，和原生 turnId 分开；只有发送才创建运行记录。
- revision：同连接中单调递增的视图版本，旧事件不得覆盖新视图。

重连后可重新建立 sessionRef，但必须恢复用户选择的同一原生会话，不能补建。
本地临时引用与正文仅留内存；完整历史由原生工具管理。

## 视图与能力

返回可序列化的运行时、会话摘要、消息、工具、配置选项、审批和原生子任务视图。
会话状态区分 ready / running / stopping / disconnected / error；运行结果另分完成、主动停止、失败、未知。
能力值仅为 unknown / supported / unsupported；列表、读取、恢复、子任务详情、独立取消、用量和 Desktop 可见性独立记录。
OpenCode 的 Desktop 模型过滤保留；其他运行时从公开接口取得可选模型，不扫描私有登录或缓存。

## 操作与事件

新增 `window.toolbox.codingAgents`：检查、选择程序 / 项目、连接 / 断开、列出 / 新建 / 恢复会话、配置、发送、停止、审批、外部入口与事件订阅。
新建和恢复是不同意图；缺失会话参数不得被当作隐式新建。发送必须传 sessionRef。
renderer 可在用户点击首次发送时，依次调用现有连接、新建、发送方法；不新增复合 IPC。切换、读历史与转用仍不发送。
事件按连接所有者窗口投递，携带 runtimeId、connectionId、revision；会话快照包含 runId。
同一运行只有一个终态；增量与最终正文按原生 item 标识核对，不重复追加。
默认全局只有一个 Tool_box 顶层运行；原生子代理内部并发仍由原生工具负责。

新增输入经 `ipc/validation.ts` 校验：运行时白名单、原始字符串长度、非空与布尔值。
不开放任意 RPC、shell 字符串、通用文件访问或凭据接口。未知审批只拒绝或提示不支持。
取消只作用于对应运行，超时 / 断连显示结果未知；不自动重发、不向其他工具广播。

## 兼容与验收

保留 `window.toolbox.opencode`、原生类型和旧 IPC；统一服务包装同一 OpenCode 实例。
旧入口与新入口共用运行互斥和连接所有权；renderer 只消费其中一条事件流。
旧 preload 时保留明确提示或兼容 OpenCode 路径；不伪造其他 Agent 可用。
验收：连接 / 切换 / 历史失败不补建；重复点击不双发；迟到事件不串会话；审批不能跨运行；同名原生 ID 不跨运行时合并。
