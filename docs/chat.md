# AI 助手与对话工具

对话页承载 AI 助手与 Agent 工具：多档案切换、流式输出、三档权限与写操作审批。
本文只写对话与工具的现行契约；上下文压缩见 `context-management.md`，知识库检索见 `knowledge-base.md`。

## 1. 对话与工具

- 支持多档案配置；API Key 经 `safeStorage` 与 AES-256-GCM 加密落库，只在主进程使用，渲染层只拿脱敏视图（如 `hasApiKey`）。
- 流式输出、可停止；主动停止与失败分开提示，运行期请求在 `finally` 清理。
- 权限三档：`readonly` 只读 / `confirm` 写操作确认 / `full` 完全访问，默认 `confirm`。
- 只读工具直接执行；写与破坏性工具必须经审批卡，审批卡展示对象、参数预览与风险级别，可滚动查看完整内容。
- **不渲染工具调用卡片**：查书架、读分组这类后台动作不占界面，只有需要确认的写操作弹出审批卡。
- 工具结果里的内部入口统一收集、去重、限量后追加到回答正文，随消息正文一起保存。
- 单轮回答最多 40 个内部入口，超出时保留较新的结果。

## 2. 引用与打开

- 内部地址格式 `toolbox://open/...`，由主进程从成功工具结果生成并做白名单校验。
- 支持对象：笔记、待办、书籍与具体章节、分组、带筛选条件的用量页、知识库文档与分块。
- 白名单排除写操作、任意路径与未知参数；不注册系统协议，禁止转交系统 shell。
- 仅桌面对话把内部地址渲染成按钮；外部 HTTP 链接维持原有打开行为。
- 点击前重新检查对象是否存在，失效显示提示；旧的异步导航会被拦截。
- 打开入口不启动模型、不修改待办，也不直接写阅读进度（进入阅读器后沿用原有记录规则）。
- 导航沿用未保存修改保护，不覆盖待办编辑草稿。
- 删除目标只在对应回答显示一次提示，不重复打扰。

## 3. 笔记局部编辑

- 工具 `notes_edit` 支持追加、唯一原文片段替换、仅改名；整篇读写工具语义不变。
- 单篇上限 20,000 字符；超过时提示到记事本页面处理，不静默截断。
- 差异预览在审批卡里完整展示，即使权限为完全访问也必须核对后确认。
- 差异文本超过 80,000 字符时拒绝，转到记事本页面处理。
- 保存前复核 ID、标题、正文与更新时间，拒绝覆盖等待期间产生的新版本。
- 同一原文片段多处命中时要求更精确的片段，不猜测替换位置。

## 4. 跨模块搜索

- `workspace_search` 必须有关键词，可指定笔记 / 待办 / 书籍 / 分组四个域。
- 每域默认 5 条、最多 10 条，返回来源、摘要、总数与截断提示。
- 待办包含未完成、已完成与归档，并返回状态。
- 书籍只搜书名与作者，不搜正文；密码箱与聊天历史不参与。
- 结果中的对象可转成内部入口，按 §2 打开。

## 5. 待办工具

- 查询沿用未完成 / 今日 / 待开始 / 逾期 / 已完成 / 归档筛选与分页。
- 修改前必须先取得 ID：可选字段未传时保留原值，显式空日期表示清除。
- 日期使用本机时间 `YYYY-MM-DD HH:mm[:ss]`，拒绝无效日期与夏令时缺口。
- 审批期间对象发生变化时拒绝写入，不覆盖并发修改。
- 写入与页面共用刷新与提醒检查入口；不提供物理删除。通知边界仍为应用运行或托盘驻留。

## 6. 用量工具

- 复用统计服务实例与缓存，参数经主进程校验；不读取正文与认证数据，也不估算费用。
- 支持今日、昨日、本周、上周、本月、近七 / 三十日、自定义与累计。
- 环比使用相邻等长自然日；基期为零或未知时不伪造百分比。
- 返回有界排行与趋势：排行 20 项、趋势最近 93 个有记录日、项目与模型目录各 50 项，超出标记截断。
- 缺少字段、未知时间与来源状态如实返回。

## 7. 流式输出与非会话调用

- 统一停止入口 `tools:ai:stop`；增量事件只发给发起请求的窗口（`WINDOW_EVENT.aiOutput`）。
- 请求用 `requestId` 归属与隔离，输入变化后旧请求的增量不再应用。
- 窗口销毁、页面重载或渲染进程退出时取消请求；结束时清理监听与活动表，拒绝重复生成。
- 非会话调用保留 `complete` 的完整返回值，底层走真实分片：不写聊天记录、不启用工具、不写会话历史。
- 提示词美化：输入与输出各 ≤ 12,000 字符；必须保留每个 `{{变量}}` 的原文与出现次数，丢失或新增时拒绝采用；处理中不重复请求，输入变化不应用旧响应。
- 密码 AI 识别：完整对象闭合后才追加脱敏预览，最多 200 条；不传输原始 JSON 或明文密码；全部校验通过后才允许导入。

## 8. 权限与审批

- 只读档位不下发写工具；写与破坏性工具在 `confirm` 与 `full` 下都要确认。
- 审批通过后仍复核对象状态，避免对已删除或已变更对象执行写入。
- 用户拒绝或停止时不写入，返回可读说明。
- 审批卡与工具参数预览使用既有主题与按钮类，不新造控件。

## 9. 上下文与知识库

- 上下文占用、自动压缩、检查点与 `chat:context` / `chat:compact` 见 `context-management.md`。
- 知识库导入、检索、引用与降级见 `knowledge-base.md`。

## 10. 明确不做

- 不在对话里展示工具调用卡片或工具轨迹。
- 不把 `toolbox://` 内部地址交给系统 shell 或注册为系统协议。
- 不让 `workspace_search` 覆盖密码箱、聊天历史或小说正文。
- 不在非会话调用里写聊天记录或启用 Agent 工具。
