# 工具扩展方向规划

日期：2026-10-25

状态：候选清单，未授权实施。本文只记录方向、代价与优先级，不代表已同意新增工具、修改 schema / IPC / 加密链路或引入第三方依赖；上述变更均须按 `AGENTS.md` 另行确认。

2026-10-25 后续授权：用户已选择 MyBatis SQL 还原、颜色／单位／进制／时区、待办开始／截止提醒，并单独同意待办 schema v5／IPC／通知事件。实施范围以 [首批规格](SPEC-tool-expansion-first-batch.md) 为准，其余候选仍未授权。

## 1. 目标与判断标准

目标不是把工具箱做成大而全的软件集合，而是让桌面端在本地完成更多高频事情，并让新增能力能被现有 AI 助手调用，而不是各做一套孤岛。

新增工具按以下顺序筛选：

1. **本地能完成**：不依赖云服务，数据默认留在本机。
2. **能复用现有能力**：SQLite 数据层、AES 加密、AI 配置档案、阅读与笔记数据、Agent 工具审批门。
3. **桌面端有优势**：文件系统、剪贴板、托盘、全局快捷键、本机进程与端口。
4. **有明确使用场景**：能说清“什么时候会点开它”，不为凑数加工具。
5. **可被 Agent 使用**：适合的工具同时注册为 Agent 工具，并按现有 risk 分级接受审批。

### 代价与影响标记

| 标记 | 含义 |
| --- | --- |
| 纯渲染 | 只改渲染层或 `src/shared/` 纯逻辑，不新增主进程能力 |
| 主进程 | 需要新增 IPC、文件 / 网络 / 剪贴板 / 系统能力，按四处同步规则修改 |
| 新表 | 需要新增数据实体或字段，属于 schema 变更，须先授权并写迁移与回滚 |
| 新依赖 | 需要引入第三方包，须先授权并评估打包、体积与许可 |
| 加密链路 | 涉及主密钥、AES-GCM 或敏感字段存储，须单独评审 |
| Agent 工具 | 可注册给 AI 助手，需定义 risk 分级与审批策略 |

工作量记号：**S** 约 1–2 天；**M** 约 3–7 天；**L** 约 1–2 周以上。仅为相对估算，不作为排期承诺。

## 2. 现有结构与约束

- 左侧导航现有四个大类：开发工作台（编程 Agent、Token 统计、工具）、阅读空间（书架、统计）、个人管理（密码箱、记事本）、系统（设置），AI 助手「对话」独立。
- 工具注册表 `src/renderer/src/components/tools/registry.tsx` 已支持多个主树分组，但入口目前只有一个「开发工作台 → 工具」。个人管理类工具若继续塞进这里，会出现「开发者工具里放记账本」的定位冲突。
- 建议为个人管理工具新增独立入口（如「生活工具」），或把现有工具页改名为「工具」后按分组切换；加分组本身只改注册表，加入口需要调整导航与页面路由。
- 新增实体优先评估能否复用 `kv` 配置；待办、记账、摘录等真正的业务实体应走 schema 升级，禁止把结构化数据塞进配置文件。
- 渲染进程禁止直接访问 Node API；文件、网络、剪贴板、系统信息必须经主进程 IPC，并统一走 `ipc/validation.ts` 校验。
- 新增 AI 能力必须手动触发并明确提示内容会发送给模型服务，不自动上传。

## 3. 个人管理：工具候选

当前只有密码箱和记事本，偏「存」，缺日常高频的「用」。

| 工具 | 核心能力 | 影响面 | 工作量 | 优先级 |
| --- | --- | --- | --- | --- |
| **待办清单** | 收集箱 / 今日 / 本周，优先级、截止日、完成记录；可由 AI 从笔记或对话中提取待办 | 新表、Agent 工具 | M | P0 |
| **剪贴板历史** | 最近 N 条文本 / 图片，搜索、固定、一键回填；默认关闭，退出清空，排除密码类内容 | 主进程、新表、隐私设计 | M | P0 |
| **快速文本片段** | 常用地址、客服话术、命令、签名；搜索后一键复制；支持 `{{变量}}` | 主进程（快捷键）、新表或 `kv` | M | P1 |
| **纪念日 / 生日 / 订阅到期** | 倒计时列表，支持农历与每年重复；托盘或系统通知提醒 | 新表、通知 | M | P1 |
| **证件 / 许可证保险箱** | 身份证、银行卡、软件 License、密钥备份；复用密码箱加密链路，带到期提醒 | 新表、加密链路 | M | P1 |
| **习惯打卡 / 番茄钟** | 日历热力图、连续天数、托盘倒计时 | 新表 | M | P2 |
| **家庭物品 / 保修管理** | 物品、购买日期、保修到期、票据图片 | 新表、主进程文件 | M | P2 |
| **记账小本** | 快速记一笔、分类、月度图表、CSV 导出 | 新表、完整页面 | L | P2 |
| **健康记录** | 体重、血压、用药记录，趋势图与导出 | 新表、隐私设计 | M | P2 |

推荐组合：先做**待办清单 + 剪贴板历史**，再补**纪念日 / 订阅提醒**。证件保险箱放在加密方案单独评审之后；记账属于完整模块，最后再评估。

## 4. 开发工作台：工具候选

现有工具偏文本处理，缺联网调试、文件处理和代码资产沉淀。

| 工具 | 核心能力 | 影响面 | 工作量 | 优先级 |
| --- | --- | --- | --- | --- |
| **MyBatis 日志还原 SQL** | 从 `Preparing / Parameters` 还原可执行 SQL，支持批量与脱敏 | 纯渲染 / 共享逻辑 | S | P0 |
| **颜色工具** | HEX / RGB / HSL 转换、WCAG 对比度、渐变 CSS、取色板 | 纯渲染 | S | P0 |
| **单位 / 进制 / 时区换算** | 世界时钟、时间差、字节单位、进制转换 | 纯渲染 | S | P0 |
| **cURL ↔ 代码片段** | cURL 转 Java / JS / Python，或反向生成 | 纯渲染 | S | P0 |
| **HTTP 请求调试（轻量 Postman）** | 方法、地址、请求头、请求体、响应查看；保存集合、环境变量、历史；与 cURL 互转 | 主进程、网络、新表 | L | P1 |
| **SQL 工具箱** | 格式化、参数占位、提取表名；首版不直连数据库 | 纯渲染 / 共享逻辑 | S–M | P1 |
| **代码片段库** | 常用工具类、命令、配置模板，按语言 / 标签搜索，一键复制或填入 Agent 草稿 | 新表、Agent 工具 | M | P1 |
| **文件夹差异比较** | 递归比较目录，忽略规则，显示新增 / 删除 / 修改 | 主进程文件 | M | P1 |
| **Git 仓库速览** | 当前分支、未提交改动、最近提交、diff 统计；只读，不执行危险命令 | 主进程 | M | P1 |
| **二维码生成 / 识别** | 离线生成、从图片识别 | 纯渲染 / 新依赖 | M | P2 |
| **JSON Schema / OpenAPI 查看器** | 校验、格式化、生成示例 | 纯渲染 | S–M | P2 |
| **Mock 数据生成** | 按 Schema 生成假数据，导出 JSON / CSV / SQL | 纯渲染 / 共享逻辑 | M | P2 |
| **日志实时追踪** | `tail -f`、关键字高亮、过滤 | 主进程文件 | M | P2 |
| **HAR 查看器** | 查看浏览器导出的请求 / 响应，排查线上问题 | 纯渲染 | M | P2 |

最划算的首批：**MyBatis 日志还原 SQL、颜色工具、单位 / 时区、cURL 转代码**。HTTP 请求调试是最大的投入，做成后能显著提升「开发工作台」的存在感，但须确保请求头中的 Token 不落盘、不写日志。

| --- | --- | --- | --- | --- |
| **摘录 / 划线管理** | 选中文字生成摘录，按书 / 章节 / 标签管理，可存入笔记 | 新表、Agent 工具 | M | P0 |

| **人物 / 设定词典** | 手动或 AI 从章节抽取人物、别名、关系；本地保存 | 新表、AI 手动触发 | M–L | P2 |

## 7. 可新增的大类

### 7.1 安全与隐私（推荐）

理由：密码箱的 AES-256-GCM 与主密钥链路已经存在，扩展成本最低，也最符合本地优先定位。

候选工具：

- TOTP 两步验证码
- 文本 / 文件加密解密（AES-GCM，本地）
- HMAC / 密钥对生成
- 密码健康报告（重复、弱、长期未改、解密失败）
- 安全笔记（加密笔记，与普通笔记分开）
- 图片 EXIF / 文档元数据清理
- 剪贴板敏感内容清理
- 证件 / 银行卡 / 许可证保险箱

风险：涉及加密链路与敏感数据，必须单独评审；不得为省事把主密钥写入日志或明文配置。

### 7.2 文件与媒体（推荐）

理由：网页工具做不了的文件操作，正好是桌面端优势。

候选工具：

- 批量重命名（正则、序号、日期）
- 图片压缩 / 格式转换 / 去 EXIF
- 文件哈希、重复文件查找
- 大文件 / 大目录扫描
- 压缩包预览与解压
- 文件夹对比
- 二维码生成 / 识别

风险：文件操作必须有路径校验、覆盖确认和失败回滚提示；首版不做删除类批量操作。

### 7.3 效率与时间

候选工具：待办清单、番茄钟 / 倒计时、世界时钟 / 时区转换、习惯打卡、快速记录、剪贴板历史、常用文本片段。

与个人管理有重叠，建议二选一：要么并入「个人管理」，要么单独成为「效率」大类，避免同一工具出现两个入口。

### 7.4 生活与财务

候选工具：记账 / 月度报表、订阅管理与续费提醒、纪念日 / 生日、保修与票据、健康记录。

这类工具数据敏感度和长期维护成本都较高，建议先做单点工具，不做完整财务系统。

### 7.5 知识库 / 学习

候选工具：摘录收件箱、闪卡 / 间隔重复、术语表 / 人物词典、网页收藏 / 稍后读、每日回顾。

与阅读空间、记事本重叠较多，可作为阅读空间的二级分组，而不是新开大类。

### 7.6 AI 工作台（可选）

现有 AI 助手、Prompt 模板、提示词美化已覆盖不少，不建议单独铺大。若要扩展，优先做单点工具：

- 批量翻译 / 批量摘要
- 图片 OCR / 看图提取文字
- 写作润色 / 改写 / 扩写模板
- 多模型对比（同一问题并排看两个模型）
- 本地文件批量总结

所有 AI 工具必须手动触发，明确提示内容会发送给当前启用的模型服务；不自动上传文件或剪贴板内容。

## 8. 推荐落地批次

### 首批（P0，先做）

1. 待办清单（个人管理）
2. 剪贴板历史或快速文本片段（个人管理；两者先选一个，避免功能重叠）
3. MyBatis 日志还原 SQL（开发工作台，成本最低）
4. 颜色工具 + 单位 / 进制 / 时区换算（开发工作台，纯前端）
5. 阅读摘录 → 笔记（阅读空间）

选择标准：高频、能复用现有能力、除待办和摘录外不强制改 schema。

### 第二批（P1）

- 证件 / 许可证保险箱
- 密码健康报告
- 纪念日 / 订阅到期提醒
- HTTP 请求调试
- 代码片段库
- 文件夹差异比较
- 阅读目标与打卡
- 章节朗读
- 编程 Agent 完成通知 / 托盘状态

### 第三批（P2）

- 记账小本
- 图片 / 文件批量工具
- EPUB / MOBI 支持
- 人物 / 设定词典
- AI 批量翻译 / 摘要 / OCR
- 习惯打卡、健康记录等生活模块

## 9. Agent 工具联动

新增模块若适合被 AI 使用，应同时注册 Agent 工具，并沿用桌面端现有约定：

- 工具名使用 `域_动作` 下划线命名，例如 `todos_list`、`todos_add`、`snippets_search`。
- 只读工具默认下发；写操作与破坏性操作必须经过审批门。
- 密码箱、证件、剪贴板等敏感数据默认不暴露给 AI，或在只读档位下也不下发。
- 工具入参统一校验，错误文案面向用户，不返回内部路径、SQL 或密钥信息。

## 10. 实现与验收要求

每个新工具落地时至少确认：

- 是否纯渲染即可完成；需要主进程时，是否已同步 `shared/types.ts`、`shared/bridge.ts`、`shared/ipc-contract.ts`、`preload/index.ts` 与对应 handler。
- 是否新增数据实体；若新增，提供 schema 升级、回滚说明与旧数据兼容处理。
- 是否新增依赖；未经授权不得安装。
- 空状态、加载失败、输入超限、长文本、大列表、重复点击是否有明确处理。
- 键盘可操作、Esc 可关闭弹层、焦点可恢复；样式复用现有设计系统，不硬编码颜色。
- 是否可在 1280×820、1024×680、1920×1080 下正常布局。
- 纯逻辑是否下沉到 `src/shared/` 并有单测；是否补充 Agent 工具与审批用例。
- 是否更新 `README.md` 的工具说明与 `docs/ROADMAP.md` 的执行状态。

验证仍遵守 `AGENTS.md` 的代码量与文件数双重门槛：文档、注释、纯样式改动不单独触发编译测试；未达门槛时由用户手动验收。

## 11. 非目标与暂缓项

- 局域网 / 云同步：主密钥绑定设备，密码箱密文天然不互通，不做暗示可同步的入口。
- 在线密码泄露查询：需要把密码或哈希前缀发给第三方，不符合本地优先；如要做，必须明确风险并默认关闭。
- 自动修改密码：仅提供健康报告与跳转，不自动改密码。
- 数据库直连执行 SQL：首版只做格式化和日志还原，不保存生产连接串。
- 后台常驻监听剪贴板：剪贴板历史默认关闭，退出清空，并提供排除规则。
- 完整记账 / 财务系统：先做单点记账工具，不扩展成多账户、资产、报表体系。

## 12. 待确认问题

1. 先做哪个方向：个人管理、开发工具快赢项，还是新开「安全与隐私」大类？
2. 是否允许新增依赖（二维码、EPUB、XLSX、图片处理等）？
3. 是否授权 schema v5 以及待办、剪贴板、摘录等新表？
4. 剪贴板历史的保留范围与隐私边界：只存本次运行、还是加密落盘？是否排除密码管理器内容？
5. 新增 Agent 工具是否继续沿用「只读默认、写操作审批」的档位，还是需要单独的开关？
