# 对话五项高优先级能力交付

日期：2026-10-25。范围由用户选择：待办、Token 查询、笔记局部编辑、跨模块搜索、结果定位与打开；其余建议未实施，未提交。

## 改动内容与原因

- `services/agent/tools/todos.ts` 与 `todo-service.ts`：四个工具提供查询、完整读取、保存和状态切换；修改合并未传字段、日期显式清除、确切 ID 和审批后快照核对。页面与对话共用刷新和提醒调度，避免对话写入后页面不更新或漏检提醒。
- `tools/usage.ts` 与 `agent-usage/create-service.ts`：共用用量实例、来源配置和缓存；支持自然日周期、精确筛选、等长前期环比、排行、每日趋势、来源状态。零基期、未知或覆盖不完整不显示虚构百分比，不输出价格、原生费用、原始记录或会话正文。
- `tools/note-edit.ts` 与 `tool-registry.ts`：追加、唯一片段替换和改名；审批前固定完整差异，批准后重新核对正文／标题／更新时间。局部编辑即使完全访问也需确认；相同原文多处出现或差异超限时拒绝，保留原笔记。
- `tools/workspace.ts`：四域搜索返回来源、摘要、总数与截断提示；待办包含未完成、已完成和归档。仅书名／作者参与书籍搜索，没有扩展小说全文、密码箱、聊天历史或模板。
- `app-reference.ts`、工具运行器、网关和 renderer 导航：从成功工具结果生成去重、有数量限制的入口，追加进原有消息正文，在真实 SQLite 历史中保存。仅桌面对话显式渲染内部地址为按钮，白名单排除写操作／任意路径／未知参数；点击前复查对象、拦截旧异步导航，不调用系统 shell。笔记读取失败统一为安全提示，删除目标只在对应回答显示一次提示。
- 统计页接收原查询条件；阅读器可指定起始章节；待办定位保留未保存的编辑草稿。审批卡支持滚动查看完整预览，使用既有主题和按钮类。

## 影响范围

桌面 main 服务依赖注入、既有 IPC handler 内部实现、renderer 与纯共享函数。`shared/types.ts`、`shared/bridge.ts`、`shared/ipc-contract.ts`、产品 preload 未改；无新增 IPC 通道、数据库迁移、依赖、加密变更、手机适配或真实 Agent 任务。内部对象地址不注册系统协议。进入阅读器后沿用原有阅读记录规则，不在导航器里直接改进度。

## 潜在风险与边界

- 真实模型需支持工具调用；此次用合成模型调用替代，不承诺所有供应商都会正确选择工具。相对日期依赖模型理解，系统提供当前本机时间／时区，含糊时要求先确认。
- 待办日期仍按本机时区解释，提醒仍需应用运行或托盘驻留；Windows 通知送达与免打扰沿用人工验收项。
- 局部笔记编辑上限 20000 字符、完整差异上限 80000 字符；超限转到记事本页面处理，不截断后悄悄写入。
- 搜索每域默认 5 项、最多 10 项；用量排行前 20 项、趋势最近 93 个有记录日、项目／模型目录前 50 项，超出标记截断。需要精确来源时继续按名称查询；入口单轮最多 40 个，保留较新的结果。
- DPI 缩放、实际输入法和屏幕阅读器仍需手动体验；本轮未打包发布，需要重启开发版本加载新工具。
