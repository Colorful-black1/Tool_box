# 桌面控件与交互

本文件只记录 AGENTS.md「UI 风格规范」未展开的控件行为：键位、日期时间输入、业务确认、焦点生命周期与步进器。颜色令牌、按钮类、弹层视觉和点击外部关闭沿用 AGENTS.md，不在此重复。

## Dropdown

- 触发按钮点击或按 ↑/↓ 打开；打开时定位到当前选中项，并滚入可视区。
- 选项超过 8 个且启用 `searchable` 时，顶部显示过滤框；过滤只匹配选项文字，大小写不敏感，打开时清空上次输入。
- ↑/↓ 上下移动高亮，到首尾即停，不循环；Home/End 跳到首项/末项。
- 过滤框获得焦点时，Home/End 按文本编辑处理，不跳选项。
- Enter 选择当前高亮项；有选项时才生效。选择后关闭并回焦触发按钮。
- Tab 关闭并回焦触发按钮；Esc 关闭并回焦触发按钮。
- 未启用过滤框时，直接键入可打印字符会跳到首个以该字符开头的选项。
- 过滤无结果显示「没有匹配项，试试其他关键词」；没有可选项显示「暂无可选项」。
- 中文输入法组合态下不响应上述按键，避免候选确认误选。
- 禁用时立即关闭；触发按钮使用 `aria-haspopup="listbox"`、`aria-expanded`，选项使用 `role="option"`、`aria-selected` 与 `aria-activedescendant`。

## 日期与时间

- 日期控件同时支持日历选择与直接键入，界面显示 `YYYY-MM-DD HH:mm[:ss]`，内部值用 `T` 分隔。
- 输入框长度按精度限制为 10 / 16 / 19；Enter 提交，失焦时若内容变化也提交；无效值显示错误并阻止提交。
- 日历弹层支持上一月/下一月、今天、清空；日期上下界由调用方传入，闰日与跨月按真实日历校验。
- 日历内 ←/→ 移动一天，↑/↓ 移动一周，PageUp/PageDown 切换月份；Tab 在弹层内循环，关闭后回焦触发按钮。
- 日期只处理墙上日期字符串，不承担时区换算；待办在写入时拒绝夏令时缺口，统计与 Cron 保留各自业务口径。
- 时间选择为 24 小时制，支持 `HH:mm` 或 `HH:mm:ss`；可直接键入，也可在时/分/秒列中点选。
- 时间列中 ←/→ 移动 1，↑/↓ 移动 3，Home/End 到 0/59；Enter 在值有效时确认。
- 现已覆盖待办开始/截止 2 处、Token 统计起止 2 处、Cron 计算起点 1 处；Cron 可视化模式另有快速填入。
- 清空返回空字符串并视为有效；分钟/秒精度由调用方指定，控件不擅自补秒。

## 业务确认与输入框

- 业务确认统一使用应用内 `confirmDialog` / `promptDialog`，替换渲染层的原生 `window.confirm` / `window.prompt`。
- 同一时间只允许一个请求；已有请求未完成时，新的请求直接按取消处理，不排队、不叠加。
- 取消、Esc、点击遮罩都返回 `null`；取消不执行任何后续动作。
- 提示输入默认最多 120 字符，确认时去除首尾空白；输入为空时确认按钮禁用。
- 确认框打开后背景不可操作；焦点进入弹层，Tab 循环，关闭后回到原触发控件。
- 等待异步结果期间不执行破坏性操作；调用方必须在 `await` 返回后重新核对草稿、会话、选中项或删除目标，不能覆盖等待期间产生的新输入。
- 窗口卸载会取消未完成的确认，不把旧结果写回新状态。

## 模态与焦点

- 模态打开时优先聚焦 `[data-autofocus]`，否则聚焦第一个可聚焦元素，再退到容器本身。
- 需要锁定背景时，弹层之外的同级容器设为 `inert`；关闭后恢复原状态。
- Tab / Shift+Tab 在弹层内循环；焦点跑到弹层外时拉回第一个可聚焦元素。
- 多个模态叠加时只有最上层接收焦点与关闭；下层保持不可交互。
- 弹层关闭后，焦点回到打开它的控件；触发控件已从 DOM 移除时保持浏览器默认行为。
- 新模态打开时，关闭不属于它的公共浮层，避免下拉或菜单悬浮在新弹层之上。
- 嵌套弹层只让最上层响应 Esc；关闭一层后焦点回到该层的触发点。

## 复选框、滑块与步进

- 复选框与滑块保留原生 `<input>` 语义和键盘能力；只统一主题令牌、轨道、滑块、选中、禁用与焦点外观。
- 复选框用 Space 切换；滑块用方向键调整，Home/End 到两端，行为保持系统原生。
- 有界整数使用 `NumberStepper`：原生数字输入加「− / ＋」按钮，`min` / `max` / `step=1`。
- 允许保留暂时无效的键入值并标记 `aria-invalid`；此时点按步进按钮从 `min` 开始，不把 `NaN` 写回业务状态。
- UUID 数量等需要明确上下界的整数使用步进器，不把数量做成无界文本输入。

## 仍需人工验收

- Windows 125% / 150% 缩放下的控件对齐、弹层边界与文字截断。
- 屏幕阅读器对 Dropdown、日历、模态焦点顺序与错误提示的朗读。
- 不同中文输入法在 Dropdown 过滤、日期时间输入和命令面板中的组合态。
- 用真实待办、Cron 与统计日期输入检查键入习惯、分钟/秒精度和跨月操作。
- 系统文件选择、另存为、系统通知与主进程退出确认仍由系统提供，不在控件层改造。
