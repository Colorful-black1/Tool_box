# 多 Agent 工作台

模块：`coding-agent-workbench`。依赖：[运行时](SPEC-coding-agent-runtime.md)。

## 交互

保留导航“编程 Agent”以及现有紧凑连接栏、会话侧栏、消息、审批和输入区。
直接切换 OpenCode / Codex / Claude Code / Claude Desktop / DSH，各自恢复已选项目、会话与草稿；首次未选项目时才继承当前项目。切换不连接、不创建、不发送。
选择项目后输入任务，首次点击“开始对话”按需连接、新建并发送；模型不可用时保留草稿与已建会话供选择。
程序路径、版本、手动连接 / 断开与外部入口收进连接设置；模型、权限与审批保持可见。
未安装 / 未接入显示原因；当前运行时不可用时，其他运行时仍可使用。

新对话按钮只进入项目草稿，首次发送才创建；历史入口连接并列出原生记录，点选恢复，已打开会话按原生身份去重。
恢复失败保留原因，不转成新建；重连保留旧草稿与失效选择，不能把它们隐式发送到新会话。
发送按钮绑定当前会话；每个运行时一次一个顶层任务，不同 Agent 的不同项目可并行，相同规范项目路径互斥，详见 [项目隔离与并行](SPEC-agent-parallel-projects.md)。
模型 / 模式只展示原生已支持选项，OpenCode 继续使用 Desktop 可见模型规则。
Desktop 可见性单独展示，不能承诺所有原生工具互见或实时同步。

原生工具和子任务合并进折叠的执行详情，按接口展示已知摘要 / 父子关系；缺少详情时明确提示，不生成虚构进度。
原生子任务不成为 Tool_box 自动团队成员，不在其他运行时建立镜像。

工具结果与 Prompt 仍只填草稿。助手完整回复可复制或直接转入另一 Agent 的同项目新对话草稿，不要求预建目标会话。
确实覆盖时确认；可明确改用已有会话，用户发送才执行。超长内容不静默截断，原生权限不随来源转移。
会话更多菜单可主动请求来源 Agent 生成交接说明，保留当前输入，结果作为普通回复转用。
旧交接弹层、来源队列与角色管理取消，已有角色配置只保留兼容校验，不自动清空。

未发送草稿继续参与已有加密保存和重启恢复，转用不会自动请求模型；“生成交接说明”是用户主动对来源会话发起的一次总结请求，沿用原生停止和审批，不额外写文件。跨项目确认与返回行为见 [项目记忆与转用](SPEC-agent-project-memory-handoff.md)。

## 原生消息回退与问答

Codex 分页会话支持“回退到此处”“回退并编辑”：从所选用户轮次之前截断原生历史，预览全部受影响可见消息摘要与轮次，确认后才执行；文件保留。后者成功后仅填草稿，用户再次发送才继续，恢复原草稿不恢复原生历史。完整历史、单次凭据、未知结果和受限表单规则见 [基础能力计划](PLAN-coding-agent-basic-features.md)。

Claude 问答／计划确认、Codex 用户提问以及 OpenCode／Codex MCP form 共用待回答区，选项不自动提交，也不批准后续工具；未支持的秘密、URL 或复杂表单回原生客户端。

## 视觉、范围与验收

复用现有 Dropdown、按钮、状态条、图标和星轨主题令牌，支持三主题、1280×820 与 1024×680。
不扩展手机端，不引入任务表、自动团队、并行 worktree、Paperclip 或插件市场。
IPC 订阅在 `App.tsx` 统一挂载和清理，Zustand 按字段订阅。
旧 preload 明确降级；迟到异步返回不覆盖另一运行时、项目或用户后续编辑的草稿。

验收：原 OpenCode 全流程无回归；连接 / 切换无隐式原生会话；发送路由唯一；历史 / 配置 / 草稿隔离；审批和停止命中原运行；缺失能力真实降级；主题与窄窗无溢出。
