# 本地数据与隐私边界

桌面端默认不出网：业务数据集中在一个 SQLite 库，敏感字段加密落库，主密钥交给系统安全区保管。本文列出四类直接接触本地数据的功能——密码箱健康检查、剪贴板历史、重复文件查找、本机快照与恢复——的读取范围、上限、失败处理与不可跨越的边界。

除用户主动发起的 AI 请求、开源热榜、模型世界与公网 IP 查询外，这些功能都不联网。渲染进程没有文件、网络与系统权限，数据只经白名单 IPC 取得。

## 数据落点

| 数据 | 位置 | 说明 |
| --- | --- | --- |
| 业务数据 | `%APPDATA%\私人百宝箱\toolbox.db` | 开发模式用 `-dev` 同级目录，与安装版互不影响 |
| 封面与背景 | 应用数据目录下 `covers/`、`backgrounds/` | 阅读器与外观资源 |
| AI 配置 | `ai-settings.json` | 供应商与模型偏好，API Key 以密文保存 |
| 主密钥 | `password-master-key.json` | 绑定当前系统用户，换机或重装系统后可能无法解密 |
| 可删缓存 | 各类 `*-cache.json` | 热榜、模型世界、Token 统计；删除只影响下次加载快慢 |

备份目标目录由用户在导出时选择，程序不主动写用户文档目录以外的位置。

## 密码箱健康检查

入口在密码箱页面工具条，打开时一次性算出报告，回答「哪些重复、哪些太弱、哪些该换」。

- 计算只发生在渲染层内存：不写日志、不进 IPC、不落盘、不发网络；报告只有条目标题、档位与天数，**不含任何明文密码**。
- 指标分别统计，同一条目可同时命中多项；解密失败的条目只计入失败数，不参与其余指标。
- 空密码单独成组，同时参与重复与弱密码统计，避免互斥分类漏报。
- 每条指标可点开看条目并跳到详情；空库或全部健康时给明确空状态。

| 指标 | 判定 |
| --- | --- |
| 重复密码组 | 同一明文出现 ≥2 次（大小写不同视为不同），只列标题 |
| 弱密码 | 强度档位为弱或很弱，列出标题与档位 |
| 空密码 | 密码为空字符串 |
| 长期未改 | 更新时间严格超过 365 天 |

健康检查不修改条目，也不提供「一键改密码」或在线泄露库查询。

## 剪贴板历史

入口是 `Ctrl+K` 命令面板，不占侧栏或工具目录。系统剪贴板没有变更事件，只能轮询；因此这项能力默认关闭，且只在本次运行内有效。

- 开启时明确提示：会记录你在本机复制的所有文本，包含其他应用复制的内容。提示不追溯开启前的复制。
- 只记录纯文本，不记录图片、富文本与文件路径列表；空白内容忽略，与上一条完全相同的内容不重复记录。
- 采集是非重叠的异步轮询，窗口不存在时不采集；关闭期间的复制不会被补录。
- 退出即清空：不写数据库、不写配置、不落盘。
- 其他应用复制的密码仍可能被记录——这正是默认关闭并要求主动确认的原因。

| 上限 | 值 | 说明 |
| --- | --- | --- |
| 条数 | 200 条 | 固定项占用同一预算；全部固定后不再采集 |
| 单条长度 | 10,000 字符 | 超出截断并在条目上标注 |
| 采集间隔 | 700 毫秒 | 关闭时完全不轮询 |
| 暂停 | 30 分钟 | 到时自动恢复，无需再次确认 |

隐私处理按优先级：

1. **应用内复制排除**：工具箱自己写入剪贴板的内容（`system:copy`，不只密码箱）按内容哈希登记，采集到同一内容时直接跳过。
2. **忽略规则**：用户可维护关键词与前缀，命中即不记录；区分大小写，按子串或前缀匹配，仅本次运行有效。
3. **固定与删除**：固定项置顶且不随上限淘汰；支持单条删除与清空全部（含固定项），清空前需确认。

面板提供时间倒序列表、搜索与点击回填；回填只写回系统剪贴板并提示已复制，不会自动粘贴到焦点窗口。

## 重复文件查找

入口在开发者工具的「文件」分组，只回答「哪些文件内容相同」，全程只读。

- 目录只能来自系统选择框，由主进程签发绑定窗口、限时有效的引用；渲染层不能传任意路径。
- 只扫描所选目录，不跨盘、不跟随符号链接与 junction，打开文件时也按不跟随链接的方式读取。
- 跳过 `.git`、`node_modules`、`out`、`release` 与点开头目录，以及带 Windows 隐藏属性或重解析点的目录。
- Windows 隐藏位不由 Node `stat` 暴露：每次扫描复用一个固定的系统命令只读查询属性；查询能力不可用或读取失败时，跳过无法确认的目录并在结果中提示，不猜。
- 先按大小分桶，只对同大小候选做流式 SHA-256；哈希前后复核大小与修改时间，扫描期间被改动或权限不足的文件跳过并提示。
- 结果只含路径、大小、份数与可释放空间估计；不提供删除、移动、重命名或硬链接替换，也不会改动文件时间戳。

| 限制 | 值 | 说明 |
| --- | --- | --- |
| 文件数 | 20,000 | 触顶明确提示「仅扫描前 N 个文件」 |
| 目录深度 | 12 层 | 更深的分支不展开 |
| 符号链接 | 不跟随 | 重解析点目录整体跳过 |
| 0 字节文件 | 不参与分组 | 结果中单独说明 |

扫描可取消、有进度，取消后不残留进度；可释放空间是内容重复的估计，不承诺硬链接或文件系统压缩后的物理释放量。

## 本机快照与恢复

主密钥由系统安全区封装并绑定当前电脑与当前用户，把库拷到另一台机器后密码箱会整体「解密失败」。因此这里只提供**本机快照**，用于同机回滚；可迁移的加密导出需要用户口令派生密钥，属于另一项需单独设计的能力，当前不提供。

| 快照内容 | 说明 |
| --- | --- |
| `toolbox.db` | 用 SQLite `db.backup()` 生成一致性副本；WAL 模式下不直接复制库文件，副本收敛为单文件日志模式以便只读校验 |
| `covers/`、`backgrounds/` | 固定资源根整份复制，受文件数与大小上限保护 |
| `ai-settings.json`、`password-master-key.json` | 只复制已存在的文件；尚未生成的密钥不会因为导出被创建 |
| `manifest.json` | 版本号、schema 版本、生成时间、文件清单与大小、SHA-256、「仅本机可恢复」标记 |

导出与恢复的边界：

- 目标是文件夹而不是 zip，不为打包新增压缩依赖；提示写明请勿上传网盘或发给他人——包里含主密钥等于交出密码箱。
- 恢复前校验文件清单、大小、哈希、格式与实际 schema；快照版本或 schema 高于当前程序时直接拒绝并说明原因。
- 二次确认写明「会覆盖当前全部数据」，覆盖前自动生成一份当前快照；准备阶段失败不会关闭当前库。
- 安装阶段在关闭数据库连接后同步执行，失败或中断按前置快照回退；成功后由程序提示退出、用户手动重开，不静默重启。
- 开始前检查运行中的对话与编程 Agent，要求先停止；关闭库之前再检查一次，不擅自终止任务。
- 恢复需要磁盘空间同时容纳前置快照、暂存文件与旧文件；失败时不清理这些诊断产物，它们含敏感数据，留在应用数据目录由用户自行处理。
- 设备与用户摘要只是误用保护，不是身份凭据；真正能否解密仍由系统安全区决定。系统重装、用户安全标识变化或安全存储环境丢失都可能让快照无法解密。
- 快照只覆盖本机业务数据与上面列出的配置；不包含外部 Agent 的原生会话、外部项目、Token 统计来源与各类缓存。

## 共同边界

- 四类功能都不新增表、不改加密算法与主密钥位置；健康检查与查重结果不落盘。
- 剪贴板文本与文件路径都在主进程处理，渲染层只拿到受限视图。
- 任何清空类操作都需要确认；文件工具从不删除文件。
- 整体覆盖只发生在快照恢复，且必须走「校验 → 前置快照 → 二次确认 → 手动重开」四步。
