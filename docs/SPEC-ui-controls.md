# 桌面控件与交互统一

日期：2026-10-25。用户已同意先提交功能基线，再按控件审查清单开始优化；基线提交 cf2f668。本轮只改渲染层，不新增依赖、不改 schema／IPC／加密，UI 改动经用户另行确认后单独提交。

## 交付顺序与边界

1. 公共弹层基础：顶层 Esc、焦点限制与返回、浮层脱离滚动容器、边界翻转。
2. 公共 Dropdown：保留现有调用契约，补上下键／Home／End／Enter／Esc、搜索、已选定位、Tab 离开与空状态。设置页两处 select、书架排序复用。
3. 日期／时间：主题日历与时间输入，替换待办两处、统计两处、Cron 一处。保留直接键入、分钟／秒精度、清空、日期上下界；控件只处理墙上日期字符串，不改变业务时区／DST 规则。
4. 业务确认／输入框：替换 renderer 的 confirm／prompt。异步等待期间禁止误操作，取消不执行，确认前复核草稿／会话状态，不能覆盖等待期间的新输入。
5. 模态抽屉／弹窗：统一焦点进入、Tab 循环、Esc 只关顶层、关闭后回原触发点。书架分组和书签管理提供可见入口，保留已有右键快捷入口。
6. 复选框与 range：保留原生语义和键盘能力，统一令牌、轨道／滑块／选中／禁用／焦点。UUID 数量使用主题步进输入。

系统文件选择、另存为、系统通知和主进程退出确认保留原生。三主题视觉保持；不扩展功能，不改 GB／GiB 的计算语义。

## 验收

- 鼠标与键盘选择、长选项搜索、空列表、禁用、窗口边缘、滚动与 resize；嵌套浮层 Esc 和焦点。
- 日历合法日期、闰年、跨月、上下界、直接键入与清空；待办本机时区、Cron 固定偏移、统计自然日不改变。
- 删除／覆盖／清除取消无副作用；重复点击、异步确认前目标变化有保护；不触发模型任务。
- 三主题、1280×820／1024×680，隔离 Electron 桩桥接截图；真实文件与用户数据库不动。
- 仅本轮增量同时超过 500 有效代码行和 10 文件后执行 typecheck → 桌面 lint → 桌面 test，再按需 build／UI 验收。之前任务代码不计入。
