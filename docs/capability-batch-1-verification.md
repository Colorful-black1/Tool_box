## 边界与风险

- 剪贴板只记录纯文本；其他应用复制的密码可能被记录，开启提示已说明。忽略规则区分大小写、按子串／前缀匹配，仅本次运行；固定项占用同一个 200 条预算，全部固定时不再采集。应用所有既有 `system:copy` 内容都排除，不只密码箱。
- 隐藏目录包含点开头目录和 Windows 隐藏属性。Node stat 不暴露 Windows 隐藏位，由每次扫描复用的一个系统 PowerShell 进程只读获取属性；固定脚本、JSON 标准输入传路径、隐藏窗口、超时与取消清理，不新增 npm 依赖。实际隐藏位由合成目录设置属性后验证跳过，普通子目录照常扫描；查询接口禁用或读取失败时跳过无法确认的目录并明确提示。文件扫描期间外部修改或权限不足的文件也会跳过并提示。空间数字是内容重复的估计，不承诺硬链接或文件系统压缩后的物理释放量。
- 设备／用户摘要是误用保护，不是不可伪造的身份凭据；实际 DPAPI 解密条件仍由系统保障。快照不是可迁移加密包；系统重装、用户安全标识变化或 DPAPI 环境丢失可能无法解密。尚未生成的密钥文件不会因导出被创建。
- 快照只包含 `toolbox.db`、`covers/`、`backgrounds/` 与已有的两份配置／主密钥文件；不包含外部 Agent 原生会话或外部项目。统计来源／缓存不在这批恢复范围。
- 恢复需要空间同时容纳前置快照、暂存和旧文件，失败时不清理这些诊断产物；它们含敏感数据，保留在应用数据目录。同步安装期间无异步业务穿插，成功后原生提示退出，不静默重启。意外中断的日志在开库前回退，损坏日志拒绝启动。
- 自动化未操作用户日常数据。真实个人数据规模、网络盘／云同步文档目录、磁盘断电与原生系统选择框的人机体验仍是实际环境边界；不以合成测试保证所有磁盘故障可恢复。
