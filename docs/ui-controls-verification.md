# 桌面控件统一交付记录

日期：2026-10-25。上一轮功能已提交：`cf2f668 feat(tools): 新增离线换算工具与待办到期提醒`。本轮 UI 改动经用户确认后单独提交。

## 改动与原因

- `components/dropdown.tsx` 与 `popover.tsx`：统一 portal、边界翻转、滚动定位、键盘选择、过滤、空状态、禁用与焦点返回；设置页两处 select 和书架排序复用。父页面流式更新不会清空过滤词，定位完成后再接管焦点。
- `date-picker.tsx`／`lib/calendar.ts`：待办开始和截止、Token 统计起止日期、Cron 起点共 5 处换成主题日历，保留键入、分钟／秒精度、今天／清空、上下界与闰日校验。日期字符串不承担时区换算，原有业务时区与 DST 规则保留。
- `app-dialog.tsx`／`stores/dialog-store.ts`：替换渲染层的业务 confirm／prompt。确认时背景不可操作，重复请求不排队；取消不执行。异步确认后复核 Agent 草稿、选择和清除目标，转用／取回保留等待期间收到的最新会话事件。
- `use-modal-focus.ts`／`use-overlay-dismiss.ts`：抽屉和弹窗接管焦点、Tab 循环、顶层 Esc、关闭后返回触发位置；记录原焦点后再锁背景，初始聚焦由公共 hook 处理。新模态打开时关闭不属于它的公共浮层。Agent「更多」菜单由 React 直接控制展开，避免原生 toggle 延迟造成 Esc 漏关。书架分组旁与书签行提供可见管理按钮，保留右键入口。
- `global.css`／`number-stepper.tsx`：三主题使用现有令牌，统一原生 checkbox 和 range 的外观及焦点态；UUID 数量增加步进按钮，保留数值输入和键盘校验。

## 风险与人工验收

- 日期键入使用固定 `YYYY-MM-DD HH:mm[:ss]` 格式；跨系统时区的解释沿用业务层。仍建议用常用待办和 Cron 输入亲自检查使用习惯。
- 截图验证覆盖两种窗口尺寸；Windows 125%／150% 缩放、屏幕阅读器和不同输入法仍需人工体验。
- 系统文件选择与真实 Windows 通知保持原实现，本轮不重复系统集成验收。
- 这些改动需要重新构建／重启正在运行的开发版本才会生效，未打包发布。
