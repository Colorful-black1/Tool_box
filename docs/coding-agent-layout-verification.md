# 编程 Agent 布局优化

日期：2026-10-29

依据用户提供的 OpenCode 截图，保留工具箱三套主题和现有执行链路，调整会话导航、输入区和常驻说明。

## 改动

- 已打开的当前 Agent／项目会话改为顶部标签。方向键只移动焦点，Enter 打开；选中已加载的标签复用本地会话，不重复请求恢复，断开的会话仍走明确恢复。
- 「＋」新对话只选择空白草稿，不提前创建原生记录。当前已是新对话时只聚焦输入，不清空正在写的内容。
- 搜索图标打开历史浮层，保留搜索、刷新和原生恢复；选择历史后收起浮层。已经读取过历史的 Claude 工作台，返回窗口仍会检查外部新增正文。
- 模式／权限、模型、思考强度直接放到输入框底栏；取消“更多模型设置”的显示门。其他原生选项也直接显示，模型仍过滤为已启用项，运行／准备中不可切换。
- 输入区的「＋」集中提供引用文件、命令、Skill、MCP，继续复用输入框上方的候选面板。选择入口不自动发送任务。
- 上下文和本轮耗时收在底栏右侧；发送／停止使用图标按钮，保留可访问名称、悬浮提示及危险操作样式。接近正文限额时才显示计数。
- 移除首次发送、Auto 可用性、空状态示例等重复说明；Enter／Shift+Enter 移入输入框悬浮提示。正常保存状态移到草稿按钮提示，保存失败、未选择项目和恢复风险仍显示。
- Claude Desktop 的会话范围与外部程序限制移到连接设置中的折叠说明，原生续接前的实际检查保持。
- 正文限制阅读宽度，宽表格与代码仍可横向滚动；输入区与正文居中，三套主题共用现有令牌。

## 影响与边界

修改 renderer 中的 workbench、sessions、composer、more-menu、context-status、draft-recovery、connection、messages，以及新建的 composer-options／composer-tools 和相关样式；更新对应隔离验收入口的定位方式。

不修改 shared 契约、IPC、主进程、数据库 schema、加密、依赖或手机端。之前一批尚未提交的基础交互实现保留，本轮没有提交 Git。

参数只来自已打开原生会话，不编造选项。第一条任务发送前尚无原生会话时，继续沿用既有默认设置；不会为展示参数提前连接／创建会话。上下文没有上报时仍显示未知。历史浮层按需读取，标签并不意味着多条同 Agent 任务可并行，原有互斥规则保持。

## 关闭标签补充

用户随后要求增加关闭能力。本次新增标签右侧关闭按钮与聚焦标签时的 Delete 快捷操作，仅更新 renderer 中按 Agent 隔离的关闭状态；不删除缓存、原生记录或草稿。关闭当前标签后优先选择右侧相邻标签，否则选择左侧，最后一个关闭后显示新对话。历史面板仍合并已关闭的缓存记录，明确打开时重新显示；晚到的会话更新不会自行重开标签。

任务执行／停止中、发送准备中、连接或会话操作处理中不接受关闭，不自动停止任务。会话缓存重建时清理旧关闭引用，不新增持久化或 IPC。

修改 `coding-agent-store.ts`、`opencode-sessions.tsx`、相关样式与 store 回归用例；保留此前未提交改动。补充草稿恢复、相邻选择、晚到事件、运行保护和 Agent 隔离用例，尚未执行。
