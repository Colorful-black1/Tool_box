# 消息转用与交接说明规格

状态：2026-10-23 用户授权易用性优化后，以下新流程替代旧交接表单与角色管理。

## 当前流程

- 用户明确选择助手回复，点击“用于 Codex / OpenCode”，进入同项目目标新对话草稿。
- 目标无需预先连接或建会话；转用不调用模型。点击发送才顺序准备连接、会话并发送。
- 可在目标草稿处展开“改用已有会话”，读取当前项目原生历史并明确选择；原草稿先保留，真正替换时确认。
- 来源名称和项目随正文展示，不再抽取最后一问一答、要求手填 diff / revision 或维护来源引用队列。
- 目标连接其他项目时先准备正确项目的草稿，不污染旧会话；后台任务仍可定位和停止。
- 当前任务进行中不转用半份结果；过长内容提示缩短或改用文档，不截断或自动分轮发送。
- 草稿与待转用内容保存在 store 内存，离开工作台再返回可以继续；退出后不承诺恢复。

## 可选来源总结

“更多 → 生成交接说明”向当前来源会话发送一次总结请求，不调用其他摘要模型，不替换用户正在写的草稿。
请求区分目标、约束、已完成 / 未完成、验证事实与待核对内容，不要求写文件或执行额外命令；权限仍由原生运行时执行。
已有合适消息或文档路径时直接使用，无需请求总结。停止沿用当前运行的原生停止能力，不自动排队或回传。

## 兼容与验收

不新增 IPC、数据库、依赖或文件访问接口。`agentRoles` 旧配置仍经原有白名单校验，未主动删除或迁移，普通 Prompt 模板库保留。
验收覆盖未连接目标转用、草稿覆盖拒绝、跨项目、历史失败、来源总结草稿保护、重连不重发和三主题双尺寸布局。
运行时真实对话、文件权限和 Desktop 互见仍独立验证；合成验收不能代替实机证据。

## 历史规格（已替代，不再作为当前交互验收条件）

状态：2026-10-23，按用户授权在 OpenCode / Codex 主线实施。

## 意图与界限

交接由用户发起，来源只取当前会话最近的请求和回复作为可编辑初稿；用户决定保留哪些上下文，并可补充 diff / revision。没有后台摘要、全历史复制、自动发送或失败换 Agent。

目标必须是已连接的另一运行时中、用户手动创建或恢复的有效会话。交接面板可以引导前往目标工作台准备会话，但不能代建。预览明确显示运行时、项目、原生标题、操作权限、源 revision 和文件不会自动同步的边界。

## 草稿与关联

填入前再次检查目标 connectionId / sessionRef；替换现有草稿须确认。只写目标内存草稿并切换查看，不调用 send。来源快照与目标关联仅保留在本次应用中，关闭后不承诺恢复。

上下文、diff、变量值、预览与关联均不写配置或 SQLite 会话表。来源引用最多保留 20 项，只有运行时 / 连接 / 会话身份与标题，可回看有效来源会话；引用不含正文。没有新增 IPC 通道、数据库表、依赖或文件读取能力。

## 可选角色预设

复用已有 Prompt 模板库，保存固定模板正文、名称、来源模板标识 / 版本与首选运行时，后续模板编辑不改变已保存快照。预设只影响提示词，不修改原生权限或子代理规则。可以不选角色直接交接。

偏好通过现有 config 桥接保存 `agentRoles: { version: 1, items: [...] }`，主进程逐项白名单校验：最多 12 项、单模板最多 12,000 字符、总模板最多 60,000 字符，标识唯一，运行时仅允许 OpenCode / Codex。仅保存可复用的非敏感模板定义，变量值不在白名单内。

## 验收

- 未连接或无有效目标会话时不能填入；准备目标不会丢失来源快照。
- 拒绝覆盖时目标草稿保留；填入后发送次数仍为零。
- 运行时 / 项目 / 会话 / 连接身份不能混用，迟到事件不覆盖预览或新草稿。
- 预设可重启恢复；只保存模板定义，源会话正文与变量值不进入配置。
- 原生子代理继续由原生运行时调度，不因交接创建镜像子任务。
