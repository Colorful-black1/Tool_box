# 桌面 UI 与编程 Agent 交互优化

日期：2026-10-28。保留现有星轨视觉与桌面布局，重点改善按钮状态和编程 Agent 的组件交互。

根据后续截图反馈，左侧树形导航采用轻量选中态：只保留当前项文字／图标颜色，不显示选中底色、圆框、阴影、发光竖条或图标放大。分类展开不套用公共按钮的展开／按下底色，键盘焦点轮廓保留。

## 影响范围

公共 CSS 与 Dropdown 会影响 AI 对话、设置、阅读、密码箱、笔记、待办、工具和 Token 统计中复用这些控件的区域；Agent 专项调整作用于工作台内的五个入口。

调用沿用 renderer → 现有 preload bridge → IPC → CodingAgentService。仅调整渲染组件及展示状态，不改 Agent 任务、权限、审批、发送／停止、历史读取、草稿落盘、IPC、数据库、加密、安全配置或依赖。手机端保持冻结。系统文件选择、另存为与通知仍由操作系统提供；折叠内容保留 HTML 键盘语义，但指示符和状态采用应用主题。

## 用户手动验收

1. 分别切换星轨、石墨、纸色主题，在 1280×820 下检查对话、设置、工具、密码箱、待办和 Token 统计里的按钮、下拉与相邻控件是否对齐。检查主／次／危险按钮的悬停、Tab 焦点、按下与禁用状态。
2. 在 Agent 工作台切换五个入口，检查较长名称和项目路径在窄窗口中的排布。选中会话后，当前项应有金色强调，长标题截断，搜索图标不遮挡文字。
3. 鼠标或键盘打开「更多」，检查上下方向键、Home／End、Enter、Tab／Shift+Tab、Esc 和外部点击。Esc 或执行操作后焦点应回到按钮；靠近窗口边缘时菜单不应溢出或被裁切。运行任务时，交接与模型同步仍按原规则禁用。
4. 打开模型下拉，搜索无匹配时应显示对应提示。键盘选项高亮和 Enter 选择一致；刷新导致列表缩短时不应指向不存在的条目。
5. 点输入区文件／命令按钮，检查展开样式与再次点击关闭。测试候选的方向键、Enter／Tab、Esc 和输入法候选确认；不应误发任务。
6. 添加长文件路径引用，检查标签换行、移除与草稿标记同步。检查字数超过 50,000 时提示色与原有禁止发送条件。
7. 检查 Enter 发送、Shift+Enter 换行、取消准备、停止任务、审批、消息转用与草稿恢复，确认原有业务行为正常；主题折叠内容应能用键盘展开。

## 风险与边界

- 公共按钮高度及圆角调整可能影响原先特别紧凑的工具条，应重点检查多按钮同行、长中文文案和系统缩放 125%／150% 的情况。
- 静态样张无法验证 Portal 实际定位、焦点恢复、输入法、异步选项变化或真实 Agent 状态切换；这些保留为手动验收项。
- 此次没有新增原生样式控件或第三方 UI 依赖，没有提交或推送。
