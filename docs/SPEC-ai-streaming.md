# AI 输出统一流式展示

AI 助手与 OpenCode 已有流式输出，本轮补齐提示词美化、桌面 / 手机密码 AI 识别。

| 能力 | 实现与边界 |
| --- | --- |
| 无会话调用 | 保留 complete 的完整返回值，底层改为真实流，增量通过回调上报，不写聊天记录 |
| 桌面传输 | 可选 requestId 保持旧调用兼容；新增 tools:ai:stop 与 WINDOW_EVENT.aiOutput；仅发送给请求窗口 |
| 提示词美化 | 实时正文预览、停止；最终校验变量后才开放复制、转模板与草稿操作；输入变更隔离旧分片 |
| 密码识别 | 完整对象闭合后追加脱敏预览，最多 200 条；不传输原始 JSON 或明文密码；完整校验后允许导入 |
| 生命周期 | 主动停止与失败分开提示，窗口销毁 / 页面关闭取消；finally 清理请求，拒绝重复生成 |
| 手机端 | 复用既有 SSE 传输与共享纯解析逻辑；支持粘贴 / 文件、停止、退出取消；不引入 LangChain |

不改数据库、加密、权限或依赖；原模板、Agent 与密码保存仍需用户显式操作。
验证仅统计本轮相对实施前快照的有效改动，满足仓库门槛后依次检查类型、Lint、单测，再构建和界面验收。
