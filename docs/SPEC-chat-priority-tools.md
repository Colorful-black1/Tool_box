# 对话高优先级能力扩展

日期：2026-10-25。用户已选择只实施上一轮清单中的五项高优先级能力。

## 能力边界与顺序

| 模块 | 职责 | 依赖 |
| --- | --- | --- |
| result-navigation | 回答中的对象入口及安全定位 | 既有页面和桥接 |
| todo-tools | 查询、新建、修改、完成／重开、归档／恢复、提醒 | 既有 v5 待办、result-navigation |
| usage-tools | 周期／来源／项目／模型、排行、趋势、环比、来源状态 | 既有用量服务、result-navigation |
| note-edit | 追加、唯一片段替换、改名、差异预览及过期保护 | 既有审批、result-navigation |
| workspace-search | 同次搜索笔记、待办、书名／作者、分组，标记来源 | todo-tools、result-navigation |

实施顺序：对象链接与内部工具扩展 → 待办 → 用量 → 笔记局部编辑 → 搜索 → 页面联调与验证。按用户已选定的五项划分，不增加中／低优先级能力。

## 具体规格

- 复用既有 IPC、schema v5、审批事件的字符串参数和消息正文。无新增通道、外部协议、依赖或加密改动；手机不参与。内部主进程依赖注入不改变 preload 契约。
- 主进程工具提供经过白名单校验的 `toolbox://open/...` 对象地址；成功结果的入口由运行器收集、去重、限量后追加到最终回答，随原有消息正文保存。仅桌面对话渲染这些地址为按钮，点击由本地导航处理，禁止转交系统 shell。外部 HTTP 链接维持原行为。
- 打开笔记、待办、书籍／具体章节、分组、带筛选的用量页；重新检查对象是否存在，失效显示提示。打开不启动模型、不修改待办；导航不直接写阅读进度，进入阅读器后沿用原有记录规则。导航沿用未保存修改保护，不覆盖待办编辑草稿。
- 待办查询沿用未完成／今日／待开始／逾期／已完成／归档筛选和分页。修改必须先取得 ID；可选字段未传时保留，显式空日期清除；日期使用本机时间 `YYYY-MM-DD HH:mm[:ss]`，拒绝无效日期与 DST 缺口。审批期间对象变化则拒绝写入。写入共用页面刷新与提醒检查入口，不物理删除。通知边界仍为应用运行／托盘驻留。
- 用量工具复用同一服务实例和缓存，参数经过现有主进程校验。默认近七个自然日；支持今日、昨日、本周、上周、本月、近七／三十日、自定义与累计。环比使用相邻等长自然日，基期零／未知时不伪造百分比。返回有界排行与趋势、缺失字段／未知时间／来源状态，不读取正文、认证或估算费用。
- 笔记新增 `notes_edit`：追加、唯一原文片段替换、仅改名。复用文本差异算法在现有审批卡显示完整有界差异；新局部编辑即使完全访问也需核对差异后确认。保存前复核 ID、标题、正文和更新时间，拒绝覆盖等待期间的新版本；同文多处命中要求更准确片段。整篇旧读写工具不改语义。
- 搜索必须有非空关键词，可指定四个域。各域有界分页和摘要，待办包含已完成／归档且返回状态，密码箱和聊天历史不加入。书籍只搜书名／作者，不扩展正文检索。
- 不顺手修复密码箱更新、长正文分段、开发工具调用、模板或编程 Agent 联动。
