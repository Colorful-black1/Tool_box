# 首批工具扩展：SQL 还原、颜色与换算、待办提醒

日期：2026-10-25。用户已选择本轮功能，并已明确同意 schema v5、新增待办 IPC／通知事件及提醒边界。仅 Windows 桌面，不新增依赖，不提交。

## 功能边界

- MyBatis：支持标准 Preparing／Parameters 行、带线程或 logger 前缀的顺序配对、批量；线程标识不同不交叉配对。参数支持 null、常用数字、布尔、字符串及日期时间；方言为 MySQL／PostgreSQL／SQLite。扫描 SQL 字符串、标识符和注释，避免替换其中的问号。不执行 SQL，不连接数据库；未知类型、歧义配对、数量不符、未结束日志明确报错，不输出伪造结果。20 万字符／200 条上限。复制与现有保存笔记／脱敏操作复用。
- 颜色：HEX／RGB／HSL 的不透明 sRGB 转换，两色预览与 WCAG 2.x 对比度；不做系统屏幕取色、透明背景混合或复杂调色板。
- 单位：长度、质量、温度、时间、十进制字节与二进制字节；不做汇率。进制：2–36 进制带符号整数，用 BigInt 避免大整数损失，不做浮点进制。
- 时区：扩展现有时间戳面板，输入明确的源时区日期时间，转换为目标时区；使用 Intl 的 IANA 时区数据。不存在的夏令时日期拒绝，重复时间明确选择较早／较晚时刻，不默猜。
- 待办：标题、备注、优先级、可选开始／截止时刻、提醒开关；默认未完成，支持完成／重开及归档。开始不晚于截止。快速新增仅填标题即可，日期时间均按本机时区输入。提供全部／今日／待开始／逾期／已完成／归档筛选和搜索。首版不做重复任务、协作、附件或自动 AI 提取。
- 通知：应用运行或驻留托盘时，每 30 秒及唤醒时检查；到开始／截止各提醒一次，完成／归档后停止提醒。修改对应时间重新安排。退出后不运行后台计划任务；重启或唤醒漏过时合并补发，已过截止不再单独补发开始通知。通知点击显示应用并定位待办。提醒关闭不通知；系统禁用／通知失败保留页面提示，不宣称成功送达。
- 新增待办首版不默认注册给模型，避免只读工具把私人待办自动送入模型上下文；工具计算也不联网。

## 数据与进程契约（已授权）

- schema v4 → v5，在 ToolboxStore 的迁移分支使用 CREATE TABLE IF NOT EXISTS 新增 todos 表与提醒／列表索引，不改旧表。
- 字段：id、title、details、priority、start_at_ms、due_at_ms、remind、completed_at_ms、archived_at_ms、start_notified_for_ms、due_notified_for_ms、created_at_ms、updated_at_ms。通知标记匹配事件时间，编辑其他字段不重复通知。表内仅普通待办内容，不存密码／密钥。
- 普通待办与现有普通笔记同样本地存储，不扩展加密链路；明确不适合保存秘密。
- 升级前备份数据库到用户数据目录的独立备份文件（SQLite VACUUM INTO 一致快照，不覆盖已有备份）；失败则停止升级并提示。迁移和 user_version 更新包在事务内。
- 回滚：退出应用，从升级前备份恢复 toolbox.db；旧程序可读取未改变的旧表，但不能读待办，且回滚会丢失升级后新数据，必须由用户手动执行。实现不删除或重置用户数据库。
- 新增 TodoInput／TodoView／TodoSnapshot／TodoEvent 普通对象类型；shared/types.ts → bridge.ts → ipc-contract.ts → preload → 主进程 handler 同步。
- IPC：todos:list、todos:save、todos:complete、todos:archive、todos:notification:test；事件 WINDOW_EVENT.todo = todos:event。列表返回分页结果（每页最多 100）及提醒可用状态；通知只发固定标题与待办标题，不发备注。
- 入参经 ipc/validation.ts 统一校验：ID ≤64、标题 1–120、备注 ≤4000、优先级枚举、布尔、有效毫秒时间／分页范围。全部 SQL 参数化；受管窗口主 frame 才能调用。
- 不为上述工具新增第三方包、全局快捷键、开机启动、系统计划任务、手机同步或其他 Agent 能力。

## 验收与风险

- SQL：字符串中的问号、逗号和引号、注释、空参数、批量／线程交错、类型不明和缺行；不可信结果不能一键复制为成功结果。
- 换算：大整数、负数、非法输入、温度、KB／KiB；IANA 非整点时区、夏令时缺口和重叠。颜色黑白对比为 21:1。
- 待办：重启持久化、校验失败保留输入、完成／重开、归档、分页、通知去重、编辑重排、禁用通知、唤醒补检、点击定位与清理计时器。
- UI：1280×820、1024×680、三主题；原生 select 禁用，复用 Dropdown／按钮／面板设计；颜色预览使用用户输入的计算结果，其他样式用设计令牌。
- 验证命令（达到门槛后）：npm run typecheck → npm run lint -- --ignore-pattern "mobile/**" → npm run test -- --exclude "mobile/**"；需要 UI 核对时再 build 和隔离 Electron 合成验收。
- 系统勿扰模式可能延后显示通知；进程崩溃与实际显示／写标记之间存在极小重复窗口，不保证操作系统级精确送达。真实 Windows 通知外观由用户最终确认，不在验证中触发真实个人待办。
