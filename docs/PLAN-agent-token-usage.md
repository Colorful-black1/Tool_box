# Agent Token 用量统计方案

日期：2026-10-24

状态：用户已授权实施，独立统计入口与 14 类来源采集已实现；实际验证与兼容边界见 [交付记录](agent-token-usage-verification.md)。用户确定只统计 Token，不做模型计价、费用估算或余额查询；2026-10-24 优化轮起仅额外展示 OpenCode 原生上报的 `cost`（非估算）。

## 目标与使用方式

在开发工作台统一查看本机常用 Agent 的历史用量，包含从各原生应用产生的记录。
统计不依赖 Tool_box 对话连接，不启动 Agent，不要求用户打开对应应用。

默认自动发现本地数据源；仅找不到或使用自定义目录时允许选择路径。
用量入口展示今日、本月、累计和自定义日期范围，支持按 Agent、项目、模型查看会话统计。
模型名称来自原始记录，无模型目录、价格表或供应商计价配置。
未检测到数据的工具不占据主视图；数据源管理中可查看检测情况、路径和兼容状态。

## 统计口径

- 仅纳入原生真实计数及可证明的直接换算；不按文本长度推算 Token，不引入计费估算。
- 只展示原生上报的花费（当前仅 OpenCode 的 `cost`）并标注覆盖度；未上报显示未上报，不建价格表。
- 展示输入、输出、缓存读取、缓存写入；推理有记录时单列，但若已属于输出，不能再加到总量。
- 各适配器声明缓存是否包含于输入；不能用同一条字段求和公式处理所有客户端。
- 缺失字段保留未知；可汇总已知部分，但须显示覆盖不完整，不能冒充全部用量。
- 累计快照不能逐条相加；不能把同一请求的增量、最终事件和会话总量重复计入。
- 去重使用客户端、原生会话与请求身份；处理分支继承、子 Agent、重试、多个目录副本和重复扫描。
- 请求数仅在可确认模型请求身份时展示，不能用对话条数代替。
- 时间以调用记录为准；只有会话汇总时不能把整份历史归入最后更新时间或伪造每日趋势。
- 项目、模型无法确认时归入未知，不从目录名猜测后当作事实。
- 日期筛选统一使用明确的本地时区边界。

## 实现边界与影响

主进程负责白名单路径发现、只读采集、归一化、去重和汇总；渲染层只展示，不直接使用 Node API。
SQLite 使用只读连接，正确读取活动 WAL；不通过复制单个 DB 或 immutable 模式忽略未合并数据。
JSONL 流式读取，文件未写完的末行延后处理；格式错误不阻塞其他数据源。
扫描异步执行，重复刷新合并，不阻塞窗口；支持文件增长、截断、替换和版本变更。
默认仅在打开用量页面时刷新与定时增量扫描，离开后停止周期扫描，保留手动刷新。
只保留统计所需元数据，不保存或输出会话正文、认证数据、密钥。

优先参考 TokLens 的采集规则、语义和合成测试，不直接搬入其 Rust/Tauri、统计数据库及界面。
压缩记录支持须先核对现有 Node 能力；新增依赖仍须用户授权，不能静默跳过后宣称完整支持。
首个实现切片优先使用内存缓存，不预设修改 toolbox.db schema；统计缓存以 JSON 落在应用数据目录，持久化另评估必要性与迁移。
新增统计 IPC / bridge、状态与界面属于后续实现范围，实施前说明契约和流程影响并遵守仓库授权要求。
不改原生数据、不改原生配置、不请求模型、不上传用量，不维护手机端。

## 实施顺序与验收

1. 建立独立统计来源列表、统一计数语义与状态；优先核实 DSH、ZCode 的身份和数据格式。
2. 接通 Codex / OpenCode 的只读扫描、去重、筛选与最小用量视图，验证全链路。
3. 接入 Claude Code、Kimi Code、Pi、WorkBuddy；目标范围不因未在本机安装而被删减。
4. 完成已确认格式的 DeepSeek harness、ZCode；逐项接入其余常用工具。
5. 核对大目录扫描、活动 WAL、半行日志、格式变化与错误隔离，并登记每个来源的支持版本和覆盖限制。

使用合成样本覆盖 Token 子集语义、累计重置、流式去重、分叉继承、重复扫描、文件变化和未知值。
真实数据验收只检查统计结果，不把真实会话内容或原生文件提交仓库。
未安装工具使用合成格式验证，并明确区分“解析用例通过”和“本机真机通过”。

命令遵循 Tool_box 的 AGENTS.md 门槛，仅当本轮同时超过 500 有效代码行和 10 个文件才允许运行：
`npm run typecheck` → `npm run lint -- --ignore-pattern "mobile/**"` → `npm run test -- --exclude "mobile/**"`。
需要构建时使用 `npm run build`，禁止 `npm run rebuild`。当前仅新增方案文档，不运行编译、测试或开发服务。

验收标准：不用连接 Agent 即可看到已保存的用量；重复刷新总量不增长；不同来源不重复计数；
缺失与不支持有明确状态；价格、美元费用、余额和模型定价配置不出现在页面或采集流程中。
