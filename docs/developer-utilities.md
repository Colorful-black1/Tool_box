# 开发者工具行为与边界

本文件记录「开发工作台 → 工具」的目录行为、各工具的能力边界、输入上限与本地处理约定。工具默认只在本机运行，不联网、不执行用户表达式或 SQL；需要主进程能力时，统一经受校验的 IPC 完成。

工具结果只用于展示、复制或转入笔记/对话草稿，不自动发送给模型。除显式保存的模板与笔记外，输入不落库。

## 工具目录与排序

### 搜索

- 匹配工具名称、描述与英文 id；NFKC 归一后转小写，多词按 AND 同时命中。
- 输入上限 100 字符；清空输入或按 Esc 恢复完整目录。
- Enter 打开当前结果中的第一个工具；中文输入法组合态下忽略 Enter/Esc，不误切换。
- 搜索只过滤左侧目录，不改变右侧面板，也不清空当前工具的输入。
- 搜索期间禁用排序与分组折叠，并提示「清空搜索后可排序」；无匹配时显示空状态。
- 切换工具前若 Prompt 模板有未保存修改，先弹出确认；取消则留在原工具。

### 排序

- 空查询下拖动工具右侧手柄，或聚焦手柄后按 Alt+↑/↓ 调整。
- 只允许当前组内部排序；拖到目标上半区插入其前，下半区插入其后；不接受外部拖入。
- 排序不切换当前工具、不清空输入；保存期间禁止再次排序。
- 顺序按工具 id 保存到配置项 `toolOrder`，不覆盖主题、阅读、模板等其他配置。
- 保存失败恢复原顺序并提示；读取失败显示默认顺序，可重试；桥接未就绪时仍可搜索和使用，但不能保存。
- 损坏、重复或已不存在的 id 会被忽略；新工具按注册顺序追加；重启后恢复已保存顺序。
- 搜索词不持久化。

## JSON 与文本

### JSON

- 支持格式化、压缩、键排序、解开字符串与 JSONPath 提取；数字按原文保留，覆盖 Java Long、指数与小数，不先转浮点。
- JSONPath 仅支持 `$`、点属性、带引号属性、非负数组下标与 `[*]`；其他语法明确报错，不执行表达式。路径最多 512 字符，命中最多 4000 项。
- 严格校验语法；重复对象键报错，避免排序、提取或比较时静默丢失字段。
- 输入上限 20 万字符、64 层嵌套、4 万节点；超限明确报错。
- 可生成 TypeScript 类型：根对象名 `Root`，根数组输出 `RootItem[]`；同形状复用接口，数组内字段不一致的对象合并并标可选；空对象/空数组回退 `Record<string, unknown>`/`unknown[]`，派生接口最多 80 个。

### 差异比较

- 文本差异按行显示新增/删除/相同，带两侧行号，可忽略空白差异。
- JSON 差异默认忽略对象字段顺序，数组顺序保留；可按字段名忽略；数字按原始数字文本比较，不转浮点。
- 每侧输入上限 20 万字符；超大可退化为公共前后缀加替换块的粗粒度结果。
- JSON 差异最多展示 300 条变更；单条预览超过 1000 字符、路径超过 1024 字符时截断并标注。

### 提示词模板

- 内置异常分析、代码审查、重构、SQL 优化、单测生成五类模板。
- `{{变量名}}` 只做一次替换，不递归解释变量内容；缺少值时提示，不静默留空。
- 自定义模板与最近 6 个历史版本经现有配置桥接保存；变量值不随模板保存，重启后不恢复。
- 模板上限 20 个、正文 1.2 万字符、历史 6 个、模板与历史总量 18 万字符；保存失败保留上次数据。
- 结果可手动送入脱敏、提示词模板、保存为新笔记或填入对话草稿；不自动发送 AI。替换已有对话草稿前先确认；桥接未就绪时仍可完成本机转换。

## Java 日志与 MyBatis

### Java 日志

- 清理 ANSI 控制符，保留原文另存整理结果；转义展开为显式开关。
- 展示异常链与 traceId 上下文，连续重复行折叠并保留重复次数。
- traceId 筛选只做文本匹配，不用模型推测异常原因。
- 输入上限 20 万字符；traceId 最多 200 字符。复杂生产日志格式仍需人工核对。

### MyBatis 日志还原

- 配对标准 `Preparing` / `Parameters` 行，支持带线程或 logger 前缀的顺序配对与批量；线程标识不同不交叉配对。
- 参数支持 null、常用数字、布尔、字符串与日期时间；方言为 MySQL、PostgreSQL、SQLite。
- 扫描 SQL 字符串、标识符与注释，只替换这些区域外的 `?`；PostgreSQL 美元引号整体跳过。
- 不执行 SQL、不连接数据库；未知类型、配对歧义、数量不符、未闭合引号或注释明确报错，失败条目不混入可复制结果。
- 输入上限 20 万字符、一次最多 200 条 SQL、单条最多 2000 个参数。
- 复制、保存笔记、送入脱敏与现有结果流转一致。

## 转换与配置

### 颜色

- HEX / RGB / HSL 之间做不透明 sRGB 转换，显示两色预览与 WCAG 2.x 对比度。
- 不做系统屏幕取色、透明背景混合或复杂调色板。

### 单位与进制

- 单位覆盖长度、质量、温度、时间、十进制字节与二进制字节；KB 与 KiB 分开；不做汇率。
- 换算结果最多 12 位有效数字。
- 进制覆盖 2–36 的带符号整数，用 BigInt 避免大整数损失；只接受整数，不做浮点进制；输入不带 `0x` / `0b` 前缀。

### 时区

- 在时间戳面板选择来源与目标 IANA 时区，输入来源时区的 `YYYY-MM-DD HH:mm[:ss]`，转换为目标时刻。
- 使用 Intl 的 IANA 数据；不存在的夏令时时刻直接拒绝；重复时刻要求显式选择较早或较晚，不默猜。
- 原有时间戳换算保留；日期字符串不承担业务时区规则的改写。

### Spring 配置

- YAML 与 Properties 双向转换，并按展平字段比较差异。
- 支持缩进映射、块列表、字符串、普通标量、Properties 转义与续行；保留占位符和数值文本。
- 拒绝重复键、路径冲突、YAML 锚点/标签/流式集合/多行标量/多文档，不静默丢数据。
- 转换不保留注释，不解析 Spring 运行时环境优先级，也不解析占位符。
- 输入上限 10 万字符、2000 个配置字段。

### Cron

- 支持 Unix 五段、Spring 六段、Quartz 六/七段；区分星期编号与日/星期匹配规则：Unix 仅当日与星期都不含 `*` 时使用「或」匹配。
- 字段支持列表、升序区间、字段跨度内正整数步长、英文月份/星期；Spring/Quartz 支持 `L`、`W`、`#`；Quartz 特殊日期条件不与列表混用。
- 可视化逐字段生成秒/分/时/日/月/周/年（按方言显示），每个字段可选每、范围、间隔、指定；Quartz 的日与周强制一个为 `?`，切换时自动调整。
- 支持按年月日时分秒填入具体时刻，实时预览未来 10 次执行时间，最多搜索 8 年；保留手动表达式解析。
- 仅提供 UTC 与北京时间两个固定时区，不模拟夏令时，也不实际创建定时任务。

## 凭据与证书

### JWT

- JWT 三段解码，展示头、载荷与时间声明；JSON 最多 32 层、1 万节点，JWT 原文最多 32768 字符。
- 明确标注「未验证签名」，不据此认定可信；输入仅存组件内存，不保存、不发送给 AI。

### 证书

- 支持 PEM 证书链或单张 DER 文件，展示 X.509 元数据与有效期。
- 拒绝私钥、混合内容与多余尾随数据；不验证证书信任链，不把「可解析」当作「可信」。
- 证书内容最多 128 KiB、一次最多 10 张；输入仅存组件内存。

### 脱敏

- 支持敏感 JSON 字段、请求头/键值形式凭据、邮箱、手机号、身份证号与银行卡候选。
- 同一原值使用一致替身；展示分类数量与结果；不另存原值，规则仅辅助识别，结果需人工检查。
- 输入上限 20 万字符；已知凭据字段最多 200 个，超出分批处理。

## 网络与进程

### 本机与公网 IP

- 展示本机非回环网卡地址；点击「查询公网 IP」后才分别查询 IPv4 与 IPv6。
- 按顺序尝试 icanhazip、ident.me；IPv4 再回退 IPIP.net，IPv6 再回退 ipify；显示出口地址与来源，可分别复制，结果不落盘。
- 查询走系统代理；公网查询可能把出口地址暴露给第三方，默认不自动发起。

### 端口与进程

- 手动获取 Windows TCP/UDP 端口快照，展示地址、端口、状态、PID 与进程名，支持筛选、复制与确认后停止进程。
- 只执行固定系统命令并限制运行时间与输出，不暴露进程参数；非 Windows 明确提示暂不支持。
- 地址/端口/PID/进程名输入不实时筛选：按 Enter 或点击「查询端口占用」后应用；修改输入时保留上次结果并提示待查询；停止后的自动刷新仍使用已提交条件。

### 停止进程

- 只接受主进程最近一次快照签发的 `stopToken`；引用五分钟有效、单次使用、最多保留 1000 个。
- 主进程串行执行，重新检查端口归属，并在同一原生句柄上核对进程创建时间、名称与关键进程标记后再终止。
- 不结束进程树、不提权；系统关键进程、工具箱自身及身份不明项禁止停止。
- 结果只返回白名单状态与中文说明；权限不足、引用过期、端口易主或超时均不自动重试。

| 提示词模板 | 20 个模板 / 正文 1.2 万字符 / 历史 6 个 / 总量 18 万字符 | 报错；保存失败保留上次数据 |
| MyBatis | 20 万字符 / 200 条 SQL / 单条 2000 参数 | 报错 |
| Spring 配置 | 10 万字符 / 2000 字段 | 报错 |
