# Java 与 AI 开发工具首批规格

用户已确认首批五项，按本机处理、现有工具页与星轨主题实施。

| 模块 | 职责 | 依赖 |
| --- | --- | --- |
| json-tools | 无损数字解析、格式化、压缩、排序、解开字符串和常用 JSONPath | 无 |
| diff-tools | 文本逐行及 JSON 字段差异 | json-tools |
| redaction-tools | 文本与 JSON 字段脱敏、预览与统计 | json-tools |
| java-log-tools | ANSI 清理、转义展开、异常链、连续重复行折叠、traceId 筛选 | 无 |
| prompt-tools | 模板变量、保存、历史版本与版本比较 | diff-tools |

实施顺序：JSON → 差异 → 脱敏与日志 → Prompt → 结果流转与隔离验收。

## 验收边界

- JSON：数字原文保留，包括 Java Long、指数与小数；严格校验语法并限制长度/深度。
  JSONPath 支持 `$`、点属性、带引号属性、非负数组下标和 `[*]`；其他语法明确报错。
  重复对象键明确报错，避免排序、提取或比较时静默丢失信息。
- Diff：文本新增/删除/相同行可定位；JSON 默认忽略对象字段顺序，数组顺序保留；
  可按字段名忽略；数字按原始数字文本比较，不经浮点转换。大文本与结果数量均有限制。
- 脱敏：支持敏感 JSON 字段、请求头/键值形式凭据、邮箱、手机号、身份证号与银行卡候选；
  同一原值使用一致替身；展示分类数量和结果，不另存原值。规则仅辅助识别，结果需人工检查。
- Java 日志：保留原文，输出整理结果；展开转义为显式开关；展示异常链及 traceId 上下文。
  折叠保留重复次数，不使用模型推测异常原因。
- Prompt：内置异常分析、代码审查、重构、SQL 优化、单测生成模板；`{{变量名}}` 填充，
  不递归解释变量内容；缺少值时提示。自定义模板和最近六个历史版本经现有 config 桥接保存，
  主进程校验字段、长度、数量与总量；保存失败保持上次数据。变量值不随模板保存。
- 结果流转：用户手动选择送入脱敏/Prompt、保存新笔记或填入对话草稿；不自动发送 AI。
  已有对话草稿被替换前确认；笔记与模板写入失败可见；桥接未就绪时可继续本机转换。

## 安全与范围

不新增依赖，不修改数据库结构、加密链路、IPC 通道或渲染进程安全配置。
不记录输入内容；仅显式保存的模板/笔记持久化；界面按文本渲染，不执行用户表达式或代码。
本轮提供桌面入口；共享纯逻辑仍需通过手机类型与打包检查。

## 文件、风格与验证

纯逻辑与单测放 `src/shared/`；面板复用 renderer 的 Workbench、Dropdown、现有样式令牌；
Zustand 按字段订阅。保持无分号、单引号、无尾逗号风格。配置校验在 `ipc/validation.ts`。

逐片运行针对性单测；最终按顺序运行 `npm run typecheck`、`npm run lint`、`npm run test`，
再运行 `npm run build`、`npm run mobile:typecheck`、`npm run mobile:bundle`。
隔离 Electron 验收覆盖五项功能、保存失败、重启恢复、跨工具流转、三套主题与窄窗布局；
只使用合成数据，截图与临时配置不入库。不运行 `npm run rebuild`，不自动提交。
